# Registro de sesiones de usabilidad

Este archivo es para anotar a mano lo que no se alcanza a medir en la página: qué dijo cada persona, dónde dudó y qué cambiamos por eso. Las cifras (tareas logradas, tiempo y puntaje SUS) quedan guardadas solas en la base cuando la persona llena el cuestionario de la página.

Se llena después de cada sesión. No inventamos filas: una fila solo existe si la sesión ocurrió.
